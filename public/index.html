This PC — the whole app, one double-click
The site, the downloader, the song model and the voice, in one environment — one virtualenv, the voice included, not a second one — plus whatever the pool needs to reach it. It fetches its own Python 3.11 and git, installs the CUDA build of torch, all four services (site 5001, downloads 8080, song 8090, voice 8095) and the ~10 GB of model weights, then starts everything and registers it to come back at every logon. No administrator prompt and nothing to install first. About 20 GB of disk, an NVIDIA driver 560 or newer for the card, and 20–60 minutes depending on the connection; the window keeps printing what it is doing, and closing it stops the install. It asks once for the join key, which whoever runs this site gives out: that key is what adds a machine to the pool every visitor's song is rendered on. It is not printed on this page on purpose — it is a write credential for the pool, so anyone holding it could point other people's songs at a machine of their own. Without it the install still finishes and the AI runs on this PC for this PC alone.

A free GPU — nothing installed here
Open song_gpu.ipynb in Colab, choose a free T4, press Run all. That card does the same work as this PC: the song model and the voice, in one environment, with the voice reached over loopback on 8095 so there is still one address and one public door. The last cell prints one address block: press Connect my model in the header and paste that address there. If no address ever appears, this PC is most likely already the model: the Model endpoint chip in the header names the machine the site is rendering on, so there is nothing to paste and no free card is needed. Nothing is rented and this computer installs nothing. The card leaves when the Colab session ends.

Open it through that link rather than pasting the file's text into a cell: a notebook is JSON, and Colab executes pasted text as Python — NameError: name 'null' is not defined is what that looks like.

If the notebook will not open, or no cell prints anything at all, paste song_gpu_cell.py into one cell of a new notebook instead: it is plain Python, it prints before it does anything, and it needs no notebook file to load.
